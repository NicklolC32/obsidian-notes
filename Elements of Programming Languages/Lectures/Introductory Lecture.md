What is a Programming Language?
- a *formal, executable* language for defining computations
	- formal written form AKA concrete syntax
	- executable - can be implemented on computer (e.g. compiler, interpreter)
	- provide abstractions

> [!NOTE] Examples
> Examples of Non-Programming Languages and Why:
> - English - non-formal (ambiguous), non-executable (computers can't run without a translator)
> - First-Order Logic - formal, non-executable (it is declarative so describes but does not spell out how to do things)
> - prompts for AI - non-formal, executable
